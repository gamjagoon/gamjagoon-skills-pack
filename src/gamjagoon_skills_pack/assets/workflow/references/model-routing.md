# 역할과 모델 라우팅

Sol은 GPT-6.1 Sol (`gpt-6.1-sol`), Luna는 GPT-6 Luna (`gpt-6-luna`)다. 메인 에이전트는 Sol / medium을 권장한다. 설치나 프롬프트가 현재 실행 모델·추론 수준·전역 설정을 바꾸지는 않는다. 사용자가 선택한 모델과 기존 프로젝트 지시를 우선한다. 역할 파일은 지원되는 환경의 프로젝트 설정이며, 정적 설치 성공이 실제 모델·역할 호출 성공을 입증하지 않는다.

| 역할 | 모델 / 추론 | 용도 |
| --- | --- | --- |
| `gsp-triage` | Luna / low | 읽기 전용 로그·사실 추출 |
| `gsp-researcher` | Luna / medium | 읽기 전용 저장소 탐색·일차 출처 조사 |
| `gsp-worker` | Luna / medium | 격리한 지정 범위의 명확한 구현·실험 |
| `gsp-integrator` | Sol / medium | 복잡한 구현과 부모가 맡은 통합 |
| `gsp-debugger` | Sol / high | 모호하거나 위험한 디버깅 |
| `gsp-reviewer` | Sol / medium | 읽기 전용 독립 리뷰 |

작업에 맞는 역할로 직접 시작한다. 값싼 모델부터 차례로 거치는 절차는 없다. 고정 동시 실행 수, 자동 고추론 전환, 추가 외부 스킬 설치는 기본값이 아니다. 한정된 작업은 한 에이전트로 수행해도 된다.

모델이나 서브에이전트 기능을 사용할 수 없으면 그 사실과 검증 한계를 밝힌다. 현재 허용 모델로 대체해도 된다는 기존 사용자 선호가 있으면 그 범위에서만 대체한다. 그런 선호가 없으면 필요한 모델 선택 또는 기능 제공 여부만 구체적으로 묻고, 그 선택과 무관하게 가능한 작업은 계속한다. 조용히 다른 모델로 대체하거나 자체 점검을 독립 리뷰로 세지 않는다.

독립 리뷰는 130–165분 구간에 1회가 기본이다. 계획 검토가 필요하면 짧은 자체 점검으로 먼저 확인한다. 추가 독립 리뷰는 구체적 위험이나 사용자 요청이 정당화할 때만 한다. 실제 리뷰 호출을 할 수 없으면 입력 자료와 리뷰 요청을 준비하고 미실행으로 기록한다.

역할마다 [병렬 작업 계약](parallel-work.md)에 따라 소유권·cwd·근거·완료 기준을 넘긴다. 공식 기능 안내는 [Codex subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)를 참고하고 실제 실행 지원은 현재 환경에서 확인한다.
