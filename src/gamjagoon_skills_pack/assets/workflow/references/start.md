# 시작과 시계

실제 제작 작업을 받으면 원문, 기존 프로젝트 상태와 `TASK.md`를 확인한다. 설치 자체나 단순 질문에는 제작 시계를 시작하지 않는다. 사용자의 명시적 예산과 기존 기록을 우선하고 없으면 180분을 사용한다. clock 도구가 있으면 호출하고, 없으면 시스템 시계로 실제 시작·마감·시간대를 기록한다. 둘 다 불가능하면 미확인 사유를 밝히며 시각을 지어내지 않는다. 재개해도 시작과 마감을 초기화하지 않는다.

180분 기준 0–20 요구사항/최소 설계, 20–130 구현(60분 핵심 실행), 130–165 검증/독립 리뷰 1회/중요한 수정, 165–180 최종 실행/인계로 진행한다. 다른 예산은 비례 조정한다. 단계마다 승인을 요청하거나 고정 대기하지 않는다. 필요한 필수 결정만 질문하고 독립 작업은 계속한다.
