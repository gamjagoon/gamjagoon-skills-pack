# 구현

승인된 범위에서 핵심 흐름부터 작은 단위로 구현하고 각 결과를 확인한다. 180분 기준 60분까지 핵심 흐름을 실제 실행하고, 130분까지 구현에 집중한다. 예산이 다르면 비례 조정한다. 핵심 실행이 지연되면 원인을 좁히고 필수 요구사항을 보존하며 부가 범위를 줄인다. 필수 범위를 바꿔야 할 때만 근거와 권고로 결정을 요청한다.

다른 작업과 기존 변경을 보존한다. 병렬 쓰기 작업은 [격리 규칙](parallel-work.md)을 따르고 부모만 통합한다. 상태·계획 변경·실제 근거를 `TASK.md`에 갱신한다. 영향이 작은 문서 수정에 불필요한 테스트를 만들지 않는다.
