# 요구사항

상태: 2026-10-31 사용자 승인 기준. 180분 기본 개발 흐름, 프로젝트 로컬 역할 설정과 격리된 병렬 실험 지침을 제공한다.

| ID | 요구사항 | 완료 조건 |
| --- | --- | --- |
| R01 | 별도 GitHub public 저장소 `gamjagoon/gamjagoon-skills-pack` | 실제 공개 여부, 기본 브랜치와 원격 SHA 확인 |
| R02 | uv 기반 설치형 Python CLI | wheel 빌드와 격리된 `uv tool install`, Git URL 설치 경로 검증 |
| R03 | Codex 지침·원본 프롬프트·읽기 전용 리뷰어 제공 | 설치 파일 존재, 프롬프트 출력, TOML 정적 검사 |
| R04 | 새 폴더와 기존 프로젝트 지원 | dry-run 무변경, 기존 AGENTS 보존, 충돌 사전 확인, 교체 시 백업 |
| R05 | 원문의 모든 필수 요구사항과 검증 방법 추적 | TASK 템플릿과 요구사항/검토 프롬프트에 원문 근거·완료 기준 포함 |
| R06 | 요구사항·최소 설계→핵심 구현→검증·독립 리뷰→최종 실행·인계 | 180분 기본 흐름 자동 적용 지침과 선택 참조 제공; 설치기 자체의 Codex 호출 없음 |
| R07 | 기본 외부 스킬 0개, 필요한 스킬만 선택 다운로드 | 기본 init 네트워크 접근 없음; 선택 설치 출처·커밋·라이선스 안내와 설치 기록 |
| R08 | 현재 모델·권한·글로벌 설정 보존 | 글로벌/현재 주 모델 설정 보존; 승인된 프로젝트 역할만 Sol/Luna model/effort 지정, 조사·리뷰는 read-only |
| R09 | 한국어 프롬프트·가이드, 영어 검색용 README 요약 | 실행 가능한 설치·사용 예제, 역할·제한·문제 해결 설명 |
| R10 | Linux/WSL 우선 검증, MIT 원본 배포 | 로컬 플랫폼과 CI 검증 범위 보고, 외부 저작물의 라이선스 분리 |
| R11 | 오프라인 기본 사용과 명시적 외부 통신 | init/prompt/doctor 무네트워크; 선택 스킬 다운로드에는 코드·TASK·키 전송 없음 |
| R12 | 검증 근거와 한계 명시 | 단위/설치/다운로드 확인과 실제 Codex 역할 실행·터미널 검증을 구분 |
| R13 | 선택 Codex CLI 줄바꿈 로컬 설정 | 프로젝트 TOML의 입력 키만 변경, 기존 값 보존·백업·dry-run·실제 CLI 파싱 확인 |
| R14 | 사용자가 이름만 말하는 설치 흐름 | 새 폴더의 에이전트가 공개 저장소를 찾고 설치 안내를 따라 setup·검사를 수행; 사용자가 명령을 입력하지 않음 |
| R15 | 설치 단일 실행과 현재 대화 적용 | setup이 워크플로·리뷰어·줄바꿈을 사전 검사 후 하나의 트랜잭션으로 적용하고 설치 파일을 읽도록 안내 |

| R16 | 추가 프롬프트 없는 180분 기본 흐름 | setup/init 기본 180; 설치된 AGENTS와 스킬이 실제 작업에서 시간 배분·60분 첫 실행·최종 검증을 안내; 기존 예산 우선 |
| R17 | 실제 프로젝트 역할 설정과 모델 선택 지침 | Luna low/medium, Sol medium/high 역할 TOML 6개 설치·정적 검사; 사용자 전역/주 모델 유지 |
| R18 | 필요할 때 격리된 병렬 실험 | worktree/임시 복사, 변경 보존, 명시적 작업 경로, 환경·출력·포트, 결과 통합·정리 절차를 설치 자산에 제공 |
| R19 | 범용 사용법 중심 README | 특정 시험 상세와 외부 스킬 카탈로그 제외; 구성·설치·작업 흐름·역할·업데이트 설명 |

사용자는 180분 자동 적용과 두 추천안(프로젝트 역할 설정, 필요 시 격리된 병렬 작업)을 승인하고 public 게시를 요청했다. 설치기는 모델 호출이나 실험 공간 생성을 수행하지 않는다. 실제 작업을 수행하는 에이전트가 설치된 지침과 사용 가능한 도구를 따른다.
