# 독립 리뷰 1회와 수정

180분 기준 130–165분 구간에 검증과 독립 리뷰 1회를 수행한다. 원문, 최신 `TASK.md`, 관련 변경과 실제 실행 근거를 읽기 전용 `gsp-reviewer`에 제공한다. 파일·위치·발생 조건/재현·영향을 요청하고 미확인 우려를 구분한다. 부모가 중요한 결함을 수정하고 관련 확인을 다시 실행한다. 리뷰 통과를 실제 사용 성공으로 취급하지 않는다.

지원되지 않으면 [모델 대체 규칙](model-routing.md)에 따라 한계를 밝힌다. 별도 독립 리뷰 환경을 사용할 수 있을 때 같은 자료를 전달하며, 호출하지 못했으면 미실행으로 기록한다. 자체 점검은 독립 리뷰가 아니다. 추가 리뷰를 관성적으로 반복하거나 리뷰 승인을 기다리며 독립 작업을 멈추지 않는다.
