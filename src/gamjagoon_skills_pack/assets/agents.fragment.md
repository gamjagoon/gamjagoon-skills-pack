실제 제작 작업은 `.agents/skills/timeboxed-workflow/SKILL.md`를 읽고 시작한다. 단순 질문·설치 자체에는 180분 제작 절차를 적용하지 않는다. 사용자의 명시적 시간·모델·범위와 기존 `TASK.md`를 우선한다. 별도 시간 지시가 없으면 제작 예산은 180분이다. 실제 시작/마감 시각을 기록하고 재개 시 기존 시계를 유지한다. 승인된 작업은 단계마다 허락을 다시 받지 않고 진행한다.

기본 진행: 0–20분 요구사항과 최소 설계 → 20–130분 구현(60분까지 핵심 흐름 실행) → 130–165분 검증·독립 리뷰 1회·중요한 결함 수정 → 165–180분 최종 재실행·실행법·인계. 다른 예산은 비례 조정하고, 빨리 끝나면 기다리지 않는다. 원문 요구사항, 완료 기준, 결정, 실제 근거와 한계는 `TASK.md`에 유지한다. 외부 스킬은 기본 설치·작업에 추가하지 않는다.

Sol은 GPT-6.1 Sol (`gpt-6.1-sol`), Luna는 GPT-6 Luna (`gpt-6-luna`)다. 메인 모델 권장은 Sol / medium이다. 현재 실행 중인 모델이나 전역 설정을 바꾸지 않는다. 아래 역할은 작업 분리에 필요할 때만 사용하며 고정 병렬 수를 정하지 않는다.

| 역할 | 모델 / 추론 | 책임과 권한 |
| --- | --- | --- |
| `gsp-triage` | Luna / low | 로그·사실 추출, 읽기 전용 |
| `gsp-researcher` | Luna / medium | 저장소 탐색·일차 출처 조사, 읽기 전용 |
| `gsp-worker` | Luna / medium | 명확한 구현·실험, 지정된 격리 디렉터리에만 쓰기 |
| `gsp-integrator` | Sol / medium | 복잡한 구현과 결과 통합, 지정 범위에 쓰기 |
| `gsp-debugger` | Sol / high | 모호하거나 위험한 디버깅, 지정 범위에 쓰기 |
| `gsp-reviewer` | Sol / medium | 근거와 재현 조건을 갖춘 독립 검토, 읽기 전용 |

명시된 모델 선택을 존중한다. 역할·모델을 사용할 수 없으면 한계를 밝히고, 현재 허용 모델로 대체해도 된다는 기존 선호가 있을 때만 대체한다. 그렇지 않으면 필요한 선택만 구체적으로 묻고 독립 작업은 계속한다. 설치 성공은 실제 서브에이전트 실행 성공의 증거가 아니다.

병렬 작업 전 [격리·소유권·통합 규칙](.agents/skills/timeboxed-workflow/references/parallel-work.md)과 [모델 선택·대체 규칙](.agents/skills/timeboxed-workflow/references/model-routing.md)을 읽는다. 읽기 전용 탐색은 공유 저장소에서, 쓰기 실험은 별도 worktree 또는 허용 목록 복사본에서 수행한다. 각 에이전트의 실제 cwd, 수정 파일, 출력·환경·포트를 명시하고 검증한다. 부모만 결과를 통합하며 다른 작업의 변경을 보존한다.
